# PosterEngine Export QA

Use this checklist before publishing export or rendering changes.

## Formats

- PNG exports at 150, 300, and 600 DPI.
- PDF exports with crop marks enabled and disabled.
- PDF exports with margin, bleed, and safe area values at 0 and their maximum UI values.
- SVG exports use the flat SVG path by default.
- Layered SVG remains available only from the advanced export option.

## Poster States

- No markers.
- One marker.
- Fifty markers.
- Route enabled with at least two markers.
- PosterEngine copyright off.
- PosterEngine copyright on.
- Coordinates off.
- Poster text off.

## Layouts

- Print poster preset.
- Mobile wallpaper preset.
- Instagram story preset.
- Desktop wallpaper preset.
- Custom narrow and wide sizes.

## Acceptance

- Export completes without UI lockups.
- Download filename has the expected extension.
- Text remains inside the poster bounds.
- Marker and route positions match the live preview.
- PDF boxes and crop marks match the selected print settings.
- Share links restore the same location, theme, layout, text, route, and up to 50 markers.
