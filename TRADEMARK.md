# PosterEngine Brand Policy

## Ownership

The PosterEngine name, logo, visual identity, product copy, screenshots, and brand assets are separate from the source code license.

The open-source license grants rights to use, modify, and distribute the source code under its terms. It does not grant permission to use PosterEngine branding in a way that suggests official affiliation, endorsement, or ownership.

## Restricted Use

You may not use the PosterEngine name, logo, or brand assets in a way that:

- Suggests your fork, service, or product is the official PosterEngine project.
- Suggests endorsement by the PosterEngine maintainers.
- Confuses users about who operates a hosted service.
- Uses PosterEngine branding for a competing hosted product without written permission.

## Permissible Use

You may use the PosterEngine name when truthfully describing compatibility, attribution, or project history, for example:

- "Built with PosterEngine"
- "Compatible with PosterEngine exports"
- "Forked from PosterEngine"

Any such use must be clear, limited, and not presented as official branding.

## Forks and Hosted Services

Forks and hosted deployments should use their own product name, logo, domain, and visual identity unless they have written permission to use PosterEngine branding.

## Source Code License vs. Brand Rights

The Project source code is licensed under the GNU Affero General Public License v3.0 (AGPL-3.0), with earlier code covered as described in the repository license files.

The brand assets are not included in that source code license.
